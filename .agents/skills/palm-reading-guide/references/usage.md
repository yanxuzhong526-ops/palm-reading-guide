# 使用方法

## 在 Codex 中直接调用

1. 添加一张或两张手掌正面照片。
2. 输入 `$palm-reading-guide`。
3. 提供性别资料、惯用手和阅读模式。

推荐提示词：

```text
$palm-reading-guide 请分析我上传的左右手照片。我的性别资料是女性，惯用手是右手，使用现代模式。请生成完整中文报告和黑白掌纹线稿。
```

## 照片要求

- 左右手各一张时效果最好。
- 手掌正对镜头，手腕和指尖完整入镜。
- 光线柔和均匀，不使用美颜或滤镜。
- 手指自然分开，手掌不要用力绷紧。

## 一键启动器

GitHub 发布包在仓库根目录提供 `start-palm-reading.cmd`。双击后，启动器会选择图片、采集必要资料、附加照片并启动 Codex。

启动器依赖已安装并登录的 Codex CLI。它从仓库内的 `.agents/skills/palm-reading-guide` 加载 Skill，不需要先复制到个人 Skill 目录。
